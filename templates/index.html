    INSIGHTS & CONCEPTS

    Understand the structure.

    A guided tour of the algorithms running inside TreeLib.

    01

    What is a BST?

    A Binary Search Tree is a node-based structure where each node's left descendants compare smaller and its right descendants compare larger by key.

    02

    How insertion works

    Start at the root. Compare the new title; move left if smaller or right if larger. Repeat until an empty child slot is found.

    Average O(log n) · Worst O(n)
    03

    How search works

    Compare the target title at each visited node. Follow only the branch that could contain it; stop at a match or an empty link.

    O(h) time · O(1) iterative space
    04

    How deletion works

    Remove a leaf directly. Replace a one-child node with its child. For two children, replace it with its inorder successor, then remove that successor.

    O(h) time · O(h) recursive space
    05

    Height & leaf nodes

    Height counts nodes on the longest root-to-leaf path (empty tree height is 0). A leaf has no children. Tree height explains actual BST search cost.

    06

    Where trees are used

    Search indexes, ordered sets, syntax trees, routing decisions, and directory structures use tree-like ideas. Production indexes often use balanced variants.

    PROJECT OVERVIEW

    Learning meets librarianship.

    A demonstration library management system powered by a genuine Binary Search Tree.

    TL

    TREE LIB · SMART LIBRARY MANAGEMENT

    Project abstract

    TreeLib combines everyday book catalog operations with an interactive exploration of Binary Search Trees. A Flask application validates and serves library data stored in SQLite; an actual BST is inserted from database-ID order to support title lookup, traversals, and learning demonstrations.

    Problem statement

    Basic library records are easy to store, but opaque data structures make it difficult to see how searching and ordering algorithms behave on real records.

    Project objectives

    Provide reliable CRUD and issue/return flows, visualize true BST structure, compare algorithms honestly, and make core tree concepts easy to demonstrate.

    Technology stack

    Python 3.13 · Flask · SQLite · HTML · CSS · JavaScript · Chart.js (dashboard visualizations).

    Architecture

    Browser interface → Flask JSON API → SQLite books and activity tables. The server builds a title-keyed BST in persistent book-ID insertion order for tree/search/traversal requests.
